# whysogood

Fast, private, client-side web utilities platform built with Next.js 16, TypeScript, and Tailwind CSS. All processing runs directly in your browser with zero server uploads.

## Features

- **35+ Image Tools**: Compression, resizing, Apple-style interactive cropper, format conversions, EXIF viewer/stripper, DPI injector, and more.
- **Client-Side Privacy**: All processing takes place locally on your device.
- **Dark Mode First**: Clean, modern productivity interface with inline parameter validation (shadcn-inspired).
- **100% Client-Side**: No backend required; works entirely offline / as a PWA.

## Getting Started

First, install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to explore the tools.

## Build

To build the static application:

```bash
npm run build
```
